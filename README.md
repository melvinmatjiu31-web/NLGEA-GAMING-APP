# NLG EA Gaming App

## 1. Introduction

The NLG EA Gaming App is a mobile application designed to help users explore gaming packages and book gaming experiences. The application provides information about available activities, package prices, and booking options in one convenient place.

The app is designed for friends, families, gamers, and teams who want to enjoy exciting gaming experiences together.

## 2. Project Objectives

The main objectives of this application are to:

- Display available gaming packages.
- Provide information about gaming experiences.
- Show package prices and included services.
- Allow users to explore booking options.
- Provide contact information for enquiries.
- Create a simple and user-friendly mobile experience.

## 3. Features

### Home Screen
The home screen introduces users to NLG EA Gaming and provides navigation to the main sections of the application.

### Gaming Packages
Users can explore different gaming experiences, including:

1. Escape Room Challenge
2. Virtual Reality Experience
3. Racing Simulator Challenge
4. Ultimate Gamer Pass
5. Esports Training Package
6. Birthday Party Package

Each package displays information about the experience, its price, and included activities.

### Booking
The booking section allows users to explore package booking options.

### Contact
The contact section provides information to help users contact NLG EA Gaming.

### Navigation
The application includes bottom navigation to help users move between the different sections.

## 4. Technologies Used

The application was developed using:

- React Native
- JavaScript
- Expo Snack
- GitHub for source code storage and version control

## 5. Application Design

The application uses a modern gaming-inspired design with a turquoise header and colourful package sections.

The main colours include:

- Turquoise
- Orange
- Coral red
- Purple
- White

The interface is designed to make information easy to read and navigation easy to understand.

## 6. Images and Assets

The application uses gaming-related images to represent the available packages.

The images are stored in the GitHub repository and loaded into the application using image URLs.

## 7. How to Run the Application

1. Open the project in Expo Snack.
2. Allow the application to load.
3. Select the preview option.
4. Explore the home screen.
5. Navigate to the gaming packages.
6. Test the booking and contact sections.

The NLG EA Gaming App provides a convenient way for users to explore gaming packages and discover available experiences. Its simple navigation, colourful design, and package information help users interact with the gaming service.
