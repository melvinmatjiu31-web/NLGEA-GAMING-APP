# NLG EA Gaming Packages App (Expo React Native)

This project recreates the supplied mobile UI concept using a teal header, orange/coral/purple package accents, package imagery cropped from the supplied reference screenshot, and a five-item bottom navigation.

## Run in Expo Snack
1. Open https://snack.expo.dev in your browser.
2. Create a new Snack.
3. Replace the contents of `App.js` with the `App.js` from this project.
4. In the Snack file explorer, create an `assets` folder and upload all six images from this project's `assets` folder.
5. If Snack does not preserve the folder structure when uploading, use the same filenames and update each `require()` path as needed.
6. Open the preview or scan the QR code with Expo Go.

## Included screens
- Home
- About / vision / mission / goals / history
- Packages with search
- Package details, quantity selector and total
- Booking form with required-field checks and a demo confirmation
- Contact form

## Important
This is a front-end prototype. Booking requests and contact messages are not sent to a real server. Replace the sample contact details with the correct business details and connect a backend before using it in production.
